# Orij Power Solutions

Disect the uploaded image and get the logo for ORIJ POWER. Design a functional ecommerce website that does not handle direct sales of diesel generators but allows users to read the specification of the generator they want and once ready to place order are welcomed with a screen for them to either request a call/ whatsapp message or email to get the pricing of the selected generator/item. Make this a high standard website.
